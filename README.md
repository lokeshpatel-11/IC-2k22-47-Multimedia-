# Multimedia Systems Lab

**Name:** Lokesh Patel

## Clusters

This repository contains the practical implementations for the Multimedia Systems Lab.

1. **Cluster01-Image-Processing**
   Contains scripts for analyzing and processing images.
2. **Cluster02-Audio-Processing**
   Contains scripts for analyzing audio files, including an AI **Voice Cloning** tool.
3. **Cluster03-Video-Processing**
   Contains scripts for analyzing and manipulating video content.
4. **Cluster04-Voice-Cloning**
   Contains cloud API scripts (ElevenLabs and Fish Audio) to clone a custom voice and generate Text-to-Speech audio without local GPU requirement.
5. **Cluster05-Image-Optimization-and-Text-Recognition**
   Contains a script to optimize high-resolution images and perform robust Optical Character Recognition (OCR) to extract text, even from blurry or high-contrast images.
